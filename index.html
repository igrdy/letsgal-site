引擎

开发基于第三方的 AVG 创作引擎 avg-engine.com，写作即创作。

可视化剧本编辑

用 Block 编写对白、选项与条件，无需编程基础。敲下每一个字，即刻出现在预览画面里。

角色与演出

支持 Spine、Live2D、序列帧与差分立绘，内置网格动画编辑器。替换素材后所有剧本引用自动同步。

叙事地图

用叙事地图看清章节、分支与片段的关系；蓝图模式通过可视化节点组织剧情流程。

实时预览与调试

通过时间轴、变量观测和快照检查剧情走向，支持属性检查。

扩展与二次开发

引擎基于 TypeScript 全栈构建，可通过 SDK 访问全部 API，用 React 编写自定义界面。

多平台构建

支持 Windows、macOS、Web 与 Android 构建。工程与素材保存在本地。
