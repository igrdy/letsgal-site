我们使用的创作引擎

游戏开发基于第三方的 AVG / Galgame 创作引擎—— avg-engine.com。 它让「写作就是创作」成为可能，我们只需专注讲好故事。

可视化剧本编辑

用 Block 编写对白、选项与条件，无需编程基础。敲下每一个字，即刻出现在预览画面里——没有编译，没有中间态。

角色与演出系统

支持 Spine、Live2D、序列帧与差分立绘，内置网格动画编辑器。可调整镜头、滤镜与过渡动画，配置替换后所有剧本引用自动同步。

叙事地图与蓝图

用叙事地图一眼看清章节、分支与片段的关系；蓝图设计模式则通过可视化节点组织剧情流程，让复杂故事结构不再混乱。

实时预览与调试

实时预览当前画面，通过时间轴、变量观测和快照检查剧情走向。支持 OP 时间轴跳转与属性检查，调试效率大幅提升。

扩展与二次开发

引擎基于 TypeScript 全栈构建，通过 @avg-studio/sdk 访问所有 API。用 React 写游戏 UI，用 Extension 类替换内置界面、注入逻辑。

多平台构建与发布

支持 Windows、macOS、Web 和 Android 构建，自主选择发行平台。工程与素材保存在本地，创作成果与原始文件完全由你掌握。
